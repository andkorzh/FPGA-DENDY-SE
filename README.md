# FPGA-DENDY-SE
A clock-precise FPGA design for an 8-bit game console.
A simplified version of the 8-bit FPGA gaming console based on the Cyclone I EP1C3T100C8. It supports composite video output and optional RGB with an additional expansion board. Audio output is provided via PWM modulators.
